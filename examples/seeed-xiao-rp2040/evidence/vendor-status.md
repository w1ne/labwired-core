# Vendor status — Seeed Studio XIAO RP2040

Checked on 2026-11-03 against Seeed Studio's live [XIAO RP2040 product page](https://www.seeedstudio.com/XIAO-RP2040-v1-0-p-5026.html): it listed the board as **In stock**.

Seeed's [current hardware guide](https://wiki.seeedstudio.com/XIAO-RP2040/) identifies the board as using Raspberry Pi RP2040 and specifies 2 MB onboard flash and 264 KB SRAM. The same guide maps the onboard red/green/blue LEDs to GPIO17/GPIO16/GPIO25 and says the LEDs turn on when those pins are driven low.

The product listing is for the standard XIAO RP2040; this profile does not claim the separate XIAO RP2040 Plus variant.
