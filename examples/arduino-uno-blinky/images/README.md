# Arduino Uno R3 images

Authored LabWired drawings, generated by `generate.py` from one geometry:

- the R3 shield outline in inches (headers on the 0.1 in and 2.0 in rows, the
  0.16 in D7-D8 gap, the stepped right edge, the four mounting holes);
- part placement checked against Arduino's A000066 front photograph;
- pin functions from `ArduinoCore-avr` `variants/standard/pins_arduino.h` and
  the ATmega328P datasheet.

These are **not** product photographs and **not** vendor art. No vendor logo or
wordmark is drawn; the silk shows the `UNO R3` model box only.

| File | What |
|------|------|
| `board.svg` | Flat top-down illustration. Also the Playground panel illustration. |
| `pinout.svg` | Every header pin with Arduino number, AVR port bit and alternate functions |
| `generate.py` | Draws both |

```bash
python3 examples/arduino-uno-blinky/images/generate.py          # regenerate
python3 examples/arduino-uno-blinky/images/generate.py --check  # verify copies
```

The docs site builds from `docs/`, so the script also writes byte-identical
copies to `docs/assets/boards/arduino-uno/`, which the board page embeds.
