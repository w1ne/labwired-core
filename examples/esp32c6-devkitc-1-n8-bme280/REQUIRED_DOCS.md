# Source documents

- [Espressif ESP32-C6-DevKitC-1 product listing](https://www.espressif.com/products/devkits): current N8 variant and purchase links.
- [ESP32-C6-DevKitC-1 v1.2 user guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c6/esp32-c6-devkitc-1/user_guide.html): board pinout, USB-UART, GPIO6/7 headers, and 8 MB module variant.
- [ESP32-C6 datasheet](https://www.espressif.com/sites/default/files/documentation/esp32-c6_datasheet_en.pdf): chip capabilities and operating limits.
- [Bosch BME280 datasheet](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf): I²C register interface and chip identity.
- [Adafruit BME280 STEMMA QT product 2652](https://www.adafruit.com/product/2652): buyable breakout used for the modeled external device.
