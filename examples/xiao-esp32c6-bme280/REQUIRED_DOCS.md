# Source documents

- [Seeed XIAO ESP32-C6 product page](https://www.seeedstudio.com/Seeed-Studio-XIAO-ESP32C6-p-5884.html): current SKU and purchase availability.
- [Seeed XIAO ESP32-C6 getting started and pin map](https://wiki.seeedstudio.com/xiao_esp32c6_getting_started/): 4 MB flash, USB serial, D4/D5 mapping, GPIO15 user light, and GPIO9 boot button.
- [Seeed XIAO ESP32-C6 schematic](https://files.seeedstudio.com/wiki/SeeedStudio-XIAO-ESP32C6/XIAO_ESP32_C6_v1.0_SCH_260114.pdf): ESP32-C6FH4, GPIO/header nets, on-board indicator and USB connections.
- [Espressif ESP32-C6 datasheet v1.5](https://documentation.espressif.com/esp32-c6_datasheet_en.html): C6FH4 memory and peripheral behavior.
- [Bosch BME280 datasheet](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf): I²C identity and raw temperature registers.
- [Adafruit BME280 STEMMA QT product 2652](https://www.adafruit.com/product/2652): purchasable breakout and I²C interface.
