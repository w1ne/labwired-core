# STM32F407G-DISC1 vendor status

Checked **2026-11-03** on ST's live product and online store pages.

- ST's [STM32F4DISCOVERY product page](https://www.st.com/en/evaluation-tools/stm32f4discovery.html)
  identifies **STM32F407G-DISC1** as the current order code that replaces the
  original STM32F4DISCOVERY code. It marks STM32F407G-DISC1 **Active** and
  provides a direct-purchase link.
- ST's [online store listing](https://estore.st.com/en/stm32f407g-disc1-cpn.html)
  showed STM32F407G-DISC1 as **Active** and **In stock**, with **Add to cart**
  available at **$29.86 each for quantities 1–2** when checked.
- ST's [STM32F407VG product page](https://www.st.com/en/microcontrollers-microprocessors/stm32f407vg.html)
  lists the board's STM32F407VGT6 as **Active** and “Product is in volume
  production.”

This onboarding targets the current STM32F407G-DISC1 order code and its
STM32F407VGT6. It does not onboard the superseded STM32F4DISCOVERY order code
as a separately purchasable SKU.
