# Sources — Arduino UNO R4 WiFi Qwiic BME280

- Arduino [UNO R4 WiFi product page](https://store.arduino.cc/products/uno-r4-wifi): current board availability and product identity.
- Arduino [UNO R4 WiFi full pinout](https://docs.arduino.cc/resources/pinouts/ABX00087-full-pinout.pdf): Qwiic connector pins and 3.3 V warning.
- Arduino [UNO R4 WiFi schematic](https://docs.arduino.cc/resources/schematics/ABX00087-schematics.pdf): Qwiic connector and RA4M1 net mapping.
- Adafruit [BME280 STEMMA QT product page](https://www.adafruit.com/product/2652): breakout availability, interface and Qwiic compatibility.
- Bosch [BME280 datasheet](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf): register behavior and chip ID.
- Renesas [RA4M1 hardware manual](https://www.renesas.com/en/document/mah/ra4m1-group-users-manual-hardware): IIC0 register behavior.
