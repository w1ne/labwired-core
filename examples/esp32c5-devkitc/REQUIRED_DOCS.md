# Source documents used for the ESP32-C5-DevKitC-1 profile

- [ESP32-C5-DevKitC-1 v1.2 User Guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp32-c5-devkitc-1/user_guide.html): N8R8 module, UART0 pins (GPIO11/GPIO12), RGB LED GPIO27, and board revision.
- The same [ESP32-C5-DevKitC-1 v1.2 User Guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp32-c5-devkitc-1/user_guide.html): GPIO6 on J1 pin 7, GPIO10 on J1 pin 11, and GPIO7 strapping-pin warning for the BME280 wiring choice.
- [ESP32-C5-WROOM-1 & WROOM-1U Datasheet v1.3](https://documentation.espressif.com/esp32-c5-wroom-1_wroom-1u_datasheet_en.html): module configuration and current module revision.
- Espressif ESP-IDF v6.0 [C5 memory map](https://github.com/espressif/esp-idf/blob/release/v6.0/components/soc/esp32c5/include/soc/soc.h) and [register bases](https://github.com/espressif/esp-idf/blob/release/v6.0/components/soc/esp32c5/register/soc/reg_base.h): flash, HP SRAM, ROM, PCR and UART addresses.
- Espressif ESP-IDF v6.0 [C5 UART registers](https://github.com/espressif/esp-idf/blob/release/v6.0/components/soc/esp32c5/register/soc/uart_reg.h): FIFO, CLKDIV, UART register head and C6-style register tail offsets.
- Espressif ESP-IDF v6.0 [C5 PCR registers](https://github.com/espressif/esp-idf/blob/release/v6.0/components/soc/esp32c5/register/soc/pcr_reg.h): UART0 clock source selection, function-clock enable, and APB enable/reset fields.
- Espressif ESP-IDF [C5 I2C register map](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/i2c_reg.h), [register bases](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/reg_base.h), and [GPIO signal map](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/include/soc/gpio_sig_map.h): I2C0 base, command-list registers, PCR address map, and I2C SCL/SDA matrix signal indices.
- Espressif ESP-IDF [C5 GPIO registers](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/gpio_reg.h) and [IO_MUX registers](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/io_mux_reg.h): GPIO6/GPIO10 matrix selectors, GPIO27 output selector, and pad mux offsets.
- Espressif [C5 RMT register structure](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/rmt_struct.h), [C5 RMT signal indices](https://raw.githubusercontent.com/espressif/esp-idf/master/components/soc/esp32c5/include/soc/gpio_sig_map.h), and the [ESP32-C5 Technical Reference Manual](https://documentation.espressif.com/esp32-c5_technical_reference_manual_en.pdf): channel registers, shared symbol RAM, TX clock controls and GPIO-matrix signal indices.
- Espressif Arduino-ESP32's [RGB LED API example](https://github.com/espressif/arduino-esp32/blob/master/libraries/ESP32/examples/GPIO/BlinkRGB/BlinkRGB.ino) and [ESP32-C5 support table](https://github.com/espressif/arduino-esp32/blob/master/docs/en/getting_started.rst): customer-facing `rgbLedWrite` quickstart.
- Espressif ESP-IDF v6.0 [C5 interrupt source enum](https://github.com/espressif/esp-idf/blob/release/v6.0/components/soc/esp32c5/include/soc/interrupts.h): UART0 source 47, UART1 source 48, and RMT source 55.
- [ESP32-C5 Technical Reference Manual](https://documentation.espressif.com/esp32-c5_technical_reference_manual_en.pdf): GPIO output, GPIO_FUNC27_OUT_SEL_CFG, IO_MUX GPIO27 address and reset/select fields.
- Espressif [ESP32-C5-DevKitC-1 v1.2 schematic](https://dl.espressif.com/dl/schematics/SCH_ESP32-C5-DevkitC-1_V1.2_20250211.pdf): D6 is a WS2812B and its data line is GPIO27 (`RGB_CTRL`).
- [Live DigiKey N8R8 listing](https://www.digikey.com/en/products/detail/espressif-systems/ESP32-C5-DEVKITC-1-N8R8/28718162) and [Adafruit BME280 PID 2652 listing](https://www.adafruit.com/product/2652): lifecycle and availability checks recorded in [`evidence/vendor-status.md`](evidence/vendor-status.md).
