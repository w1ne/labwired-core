# Vendor status: ESP32-S2-DevKitC-1-N8R2

Checked 2026-11-11 UTC. Espressif's current DevKitC-1 guide lists the exact
`ESP32-S2-DevKitC-1-N8R2` SKU with an ESP32-S2-SOLO-2 module, 8 MB flash and
2 MB PSRAM. The same table marks the older 1R and 1RU variants EOL; this profile
does not target those parts.

- Official board guide and current SKU table: [ESP32-S2-DevKitC-1 User Guide](https://documentation.espressif.com/esp-dev-kits/en/latest/esp32s2/esp32-s2-devkitc-1/index.html)
- Official product page lists N8R2 purchasing links for DigiKey and Mouser: [ESP32-S2-DevKitC-1](https://www.espressif.com/en/dev-board/esp32-s2-devkitc-1-en)
- Live distributor page checked today: [Mouser ESP32-S2-DevKitC-1-N8R2](https://www.mouser.com/en/ProductDetail/Espressif-Systems/ESP32-S2-DevKitC-1-N8R2?qs=vvQtp7zwQdN%252BQCxJ8G2wiQ%3D%3D) showed 198 in stock and immediately dispatchable.
- Silicon register source: [ESP32-S2 Technical Reference Manual v1.3](https://documentation.espressif.com/esp32-s2_technical_reference_manual_en.pdf)

Availability is a point-in-time distributor listing. The board guide explicitly
distinguishes the listed N8R2 variant from the EOL R/RU versions.
