# Verification scope — M5Stack AtomS3-Lite

The hosted LabWired board catalog did not expose the exact AtomS3-Lite SKU when
this profile was prepared. The matching evidence is therefore the local
repository smoke in this directory, which uses the exact S3 board descriptor
and asserts GPIO35 transitions and a decoded RGB pixel. No hosted
`model_verified` result or physical-board test is claimed.
