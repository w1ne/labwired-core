# Required source documents

1. [ST NUCLEO-G431KB product page](https://www.st.com/en/evaluation-tools/nucleo-g431kb.html): exact board, Active status, and Nano-compatible connector.
2. [ST UM2397, STM32G4 Nucleo-32 board user manual](https://www.st.com/resource/en/user_manual/dm00493601-stm32g4-nucleo-32-board-mb1430-stmicroelectronics.pdf): MB1430 board wiring, default LD2 PB8, VCP USART2 PA2/PA3, and I2C1 SCL PA15 / SDA PB7 bridge connections.
3. [ST STM32G431KB product page](https://www.st.com/en/microcontrollers-microprocessors/stm32g431kb.html): exact MCU family and current status.
4. [ST DS12589, STM32G431x6/x8/xB datasheet](https://www.st.com/resource/en/datasheet/stm32g431kb.pdf): package pin mapping, memory geometry, and MCU peripheral inventory.
5. [ST RM0440, STM32G4 reference manual](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf): RCC, GPIO, USART and I2C register behavior.
6. [Bosch BME280 datasheet](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf): sensor identity and I2C register interface.
