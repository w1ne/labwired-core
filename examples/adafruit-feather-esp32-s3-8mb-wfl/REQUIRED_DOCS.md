# Required source documents

- [Adafruit product #5885](https://www.adafruit.com/product/5885): exact
  8 MB flash / no PSRAM / w.FL variant and live purchase listing.
- [Adafruit ESP32-S3 Feather pinouts](https://learn.adafruit.com/adafruit-esp32-s3-feather/pinouts):
  MAX17048 address, I2C rail, and board function details.
- [Espressif Arduino Feather S3 no-PSRAM pin map](https://github.com/espressif/arduino-esp32/blob/master/variants/adafruit_feather_esp32s3_nopsram/pins_arduino.h):
  SDA GPIO3, SCL GPIO4, and I2C power GPIO7.
- [MAX17048 product and status page](https://www.analog.com/en/products/max17048.html):
  lifecycle state and datasheet link.
- [MAX17048/MAX17049 datasheet, Rev. 7](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX17048-MAX17049.pdf):
  VCELL/SOC register addresses, formats, and scales.
