# Source documents for the Cardputer-Adv profile

- M5Stack's [live Cardputer-Adv store listing](https://shop.m5stack.com/products/m5stack-cardputer-adv-version-esp32-s3): SKU, current stock and price; the 8 MiB ESP32-S3FN8 and integrated LCD.
- M5Stack's [Cardputer-Adv product guide](https://docs.m5stack.com/en/core/Cardputer-Adv): MCU, flash, display, and board features.
- M5Stack's [Arduino compilation and upload guide](https://docs.m5stack.com/en/arduino/m5cardputer/program): confirms the M5Cardputer library and board selection apply to Cardputer-Adv.
- M5Stack's [official M5Cardputer display example](https://github.com/m5stack/M5Cardputer/blob/master/examples/Basic/display/display.ino): `M5.config()`, `M5Cardputer.begin()`, and display API usage.
- M5Stack's official [generated ESP32-S3 wiring data](https://raw.githubusercontent.com/m5stack/M5GFX/master/src/board_detect/m5/generated/esp32s3_board_data.hpp): Cardputer-Adv LCD pins, SPI3 host, ST7789V2 dimensions, offsets, rotation and inversion setting.
- The live vendor availability snapshot is recorded in [`evidence/vendor-status.md`](evidence/vendor-status.md).
