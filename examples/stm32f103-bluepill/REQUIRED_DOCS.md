# Source grounding — STM32F103C8 Blue Pill

- **Live part status and buyability:** ST's STM32F103C8 page and eStore page, recorded in [vendor-status.md](vendor-status.md).
- **Board LED/header wiring:** [VccGND original Blue Pill schematic, archived by STM32-base](https://stm32-base.org/assets/pdf/boards/original-schematic-STM32F103C8T6-Blue_Pill.pdf). PC13 sinks current through the user LED; USART1 TX/RX are PA9/PA10.
- **Part memory/peripheral facts:** [ST DS5319 medium-density STM32F103 datasheet](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf) and [RM0008 reference manual](https://www.st.com/resource/en/reference_manual/cd00171190-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf).
