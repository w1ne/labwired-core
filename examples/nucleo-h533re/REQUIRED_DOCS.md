# Required source documents (NUCLEO-H533RE)

1. [STM32H533RE datasheet](https://www.st.com/resource/en/datasheet/stm32h533re.pdf) — memory size, pinout, and alternate functions.
2. [STM32H533RE product page](https://www.st.com/en/microcontrollers-microprocessors/stm32h533re) — lifecycle and device overview.
3. [NUCLEO-H533RE product page](https://www.st.com/en/evaluation-tools/nucleo-h533re) — board lifecycle and supported form factors.
4. [NUCLEO-H533RE MB1814 C-02 schematic](https://www.st.com/resource/en/schematic_pack/mb1814-h533re-c02-schematic.pdf) — LD2/PA5, USART2 virtual COM, and Arduino D15/D14 routes.
5. [STM32H5 CMSIS device header](https://github.com/STMicroelectronics/cmsis-device-h5/blob/main/Include/stm32h533xx.h) — register addresses and interrupt names.
6. [Bosch BME280 product page](https://www.bosch-sensortec.com/en/products/environmental-sensors/humidity-sensors-bme280) and [datasheet](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf) — sensor interface, register behavior, and current delivery statement.
7. [Adafruit BME280 breakout product page](https://www.adafruit.com/product/2652) and [pinout guide](https://learn.adafruit.com/adafruit-bme280-humidity-barometric-pressure-temperature-sensor-breakout/pinouts) — purchasable breakout, wiring, level shifting, pull-ups, and default I2C address.
