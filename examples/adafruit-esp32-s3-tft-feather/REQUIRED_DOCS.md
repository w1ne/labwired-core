# Source documents for the Feather profile

- Adafruit's [ESP32-S3 TFT Feather product listing](https://www.adafruit.com/product/5483): current product availability and the integrated display.
- Adafruit's [pinout guide](https://learn.adafruit.com/adafruit-esp32-s3-tft-feather/pinouts): TFT controller, display geometry, GPIO assignments, and power-control pin.
- Adafruit's [ST7789 driver](https://github.com/adafruit/Adafruit-ST7735-Library/blob/master/Adafruit_ST7789.cpp): rotation-1 panel offsets used to select the glass window.
- Espressif's [ESP32-S3 product selector](https://products.espressif.com/product-selector): current ESP32-S3 lifecycle category.
- The live status and in-stock check are recorded in [`evidence/vendor-status.md`](evidence/vendor-status.md).
