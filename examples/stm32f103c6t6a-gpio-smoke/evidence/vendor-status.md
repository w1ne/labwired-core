# STM32F103C6T6A live vendor status

Checked live on **2026-11-05 UTC**.

- ST's [STM32F103C6 product page](https://www.st.com/en/microcontrollers-microprocessors/stm32f103c6.html)
  says **Active** and **“Product is in volume production.”** Its ordering table
  lists STM32F103C6T6A and STM32F103C6T6ATR as active orderable parts with a
  direct ST eStore purchase link.
- Mouser's [STM32F103C6T6ATR listing](https://www.mouser.com/ProductDetail/STMicroelectronics/STM32F103C6T6ATR)
  showed **2,192 in stock** when checked. This is the tape-and-reel ordering
  code for the same C6T6A silicon.
- ST's [low-density STM32F103 datasheet](https://www.st.com/resource/en/datasheet/stm32f103c6.pdf)
  documents 32 KiB flash, 10 KiB SRAM for the x6 device, the LQFP48 pinout,
  and PC13.

This is a bare-part test fixture with one externally attached LED; it does not
represent a named development board.
