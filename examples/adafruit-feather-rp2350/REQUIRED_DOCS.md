# Required source documents

1. Adafruit product page, Product ID 6000 (8 MB flash, no-PSRAM option,
   current A4 RP2350 revision, live availability):
   https://www.adafruit.com/product/6000
2. Adafruit Feather RP2350 pinout (board labels, UART0, STEMMA QT, D13 LED,
   NeoPixel, HSTX GPIO, and analog pins):
   https://learn.adafruit.com/adafruit-feather-rp2350/pinouts
3. RP2350 datasheet (memory map and peripheral register definitions):
   https://datasheets.raspberrypi.com/rp2350/rp2350-datasheet.pdf
4. Raspberry Pi pico-sdk RP2350 hardware registers:
   https://github.com/raspberrypi/pico-sdk/tree/master/src/rp2350/hardware_regs
5. Adafruit Feather RP2350 schematic (D13/GPIO7 LED polarity and connectivity):
   https://github.com/adafruit/Adafruit-Feather-RP2350-PCB/blob/main/Adafruit%20Feather%20RP2350.sch
