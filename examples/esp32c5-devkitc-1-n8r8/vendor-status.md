# ESP32-C5-DevKitC-1-N8R8 vendor status

Checked live on 2026-11-12.

Espressif's current [ESP32-C5-DevKitC-1 v1.2 User Guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp32-c5-devkitc-1/user_guide.html)
lists `ESP32-C5-DevKitC-1-N8R8` as an available board variant. The guide lists
the `ESP32-C5-WROOM-1` module, 8 MB flash, 8 MB PSRAM, and PCB antenna. It says
retail samples can be ordered through Espressif's buy-sample page. The current
guide is for board revision v1.2; this is not an EOL or archived-board page.

The [ESP32-C5 product page](https://www.espressif.com/en/products/socs/esp32-c5)
lists the C5 as a 32-bit, single-core RISC-V SoC with a maximum clock of
240 MHz and 384 KB on-chip SRAM. The [ESP SoCs catalog](https://www.espressif.com/products/socs)
lists DigiKey and Mouser links for current C5 variants.
