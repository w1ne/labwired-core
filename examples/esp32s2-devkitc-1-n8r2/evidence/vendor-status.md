# ESP32-S2-DevKitC-1-N8R2 status check

Checked 2026-11-12 for the exact board suffix used by this profile.

- Espressif's current ESP32-S2-DevKitC-1 guide lists `ESP32-S2-DevKitC-1-N8R2`
  with the recommended ESP32-S2-SOLO-2 module, 8 MiB flash and 2 MiB PSRAM.
- The same guide marks older unsuffixed / `-1R` / `-1RU` variants EOL; this
  profile does not target those variants.
- DigiKey's live listing for `ESP32-S2-DEVKITC-1-N8R2` says **Part Status:
  Active**. At the check time it showed zero on hand, so Mouser was checked as
  a second authorized distributor. Mouser's exact MPN listing showed **198
  available for immediate dispatch**.
