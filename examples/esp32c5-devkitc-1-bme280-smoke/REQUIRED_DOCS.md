# Source documents

- [ESP32-C5-DevKitC-1 v1.2 user guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp32-c5-devkitc-1/user_guide.html): exact N8R8 SKU, header mapping, board revision, and GPIO27 addressable LED.
- [ESP32-C5 datasheet](https://documentation.espressif.com/esp32-c5_datasheet_en.html): HP RISC-V core, memory sizes, GPIO count, and device capabilities.
- [ESP32-C5 technical reference manual](https://documentation.espressif.com/esp32-c5_technical_reference_manual_en.pdf): HP I2C controller, register map, GPIO matrix, and memory map.
- [Espressif ESP-IDF C5 GPIO register header](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/gpio_reg.h): GPIO output/enable registers and matrix selector offsets.
- [Espressif ESP-IDF C5 GPIO signal map](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/include/soc/gpio_sig_map.h): I2CEXT0_SCL/SDA signal IDs.
- [Espressif ESP-IDF C5 I2C register header](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/i2c_reg.h): C5 I2C0 command-list register offsets.
- [Espressif ESP-IDF C5 interrupt source table](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/include/soc/interrupts.h): I2C_EXT0 interrupt source ordinal.
- [Espressif ESP-IDF C5 IOMUX register header](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/io_mux_reg.h): GPIO5/6/7 IOMUX offsets and GPIO function selector.
- [Adafruit BME280 product page](https://www.adafruit.com/product/2652): buyable STEMMA QT breakout used as the physical component reference.
