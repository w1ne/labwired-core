# Live availability — Arduino Nano ESP32 + BME280

Checked 2026-11-10 UTC.

- Arduino's live [Nano ESP32 store listing](https://store.arduino.cc/collections/boards-modules/products/nano-esp32)
  showed SKU **ABX00092**, €20.40, and an enabled **Add to cart** control. No
  NRND or obsolete notice appeared. The manufacturer's [Nano ESP32 docs](https://docs.arduino.cc/hardware/nano-esp32)
  still list the board and link its pinout, datasheet, and schematics.
- The store currently labels the product ABX00092; Arduino's linked pinout PDF
  is still titled ABX00083. The current [Nano ESP32 cheat sheet](https://docs.arduino.cc/tutorials/nano-esp32/cheat-sheet/)
  identifies A4/A5 as GPIO11/GPIO12, which is the mapping used here.
- Adafruit product 2652, the exact BME280 STEMMA QT breakout used by this
  smoke, showed **In stock** and **Add to Cart** on its live
  [product page](https://www.adafruit.com/product/2652).

This is a catalog and retailer availability check, not physical board testing.
