# Source documents

- [ESP32-C5-DevKitC-1 v1.2 user guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp32-c5-devkitc-1/user_guide.html): exact N8R8 SKU, GPIO5 header mapping, board revision, and GPIO27 addressable LED.
- [ESP32-C5 datasheet](https://documentation.espressif.com/esp32-c5_datasheet_en.html): HP RISC-V core, memory sizes, GPIO count, and device capabilities.
- [ESP32-C5 technical reference manual](https://documentation.espressif.com/esp32-c5_technical_reference_manual_en.pdf): memory map and peripheral behavior.
- [Espressif ESP-IDF C5 GPIO register header](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/gpio_reg.h): GPIO output and enable registers.
- [Espressif ESP-IDF C5 IOMUX register header](https://github.com/espressif/esp-idf/blob/master/components/soc/esp32c5/register/soc/io_mux_reg.h): GPIO5 IOMUX offset and GPIO function selector.
