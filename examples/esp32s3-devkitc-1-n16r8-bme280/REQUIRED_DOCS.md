# Source documents

- [ESP32-S3-DevKitC-1 product page](https://www.espressif.com/en/products/devkits/esp32-s3-series/esp32-s3-devkitc-1): current board variants and purchase links.
- [ESP32-S3-DevKitC-1 v1.1 user guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html): board pinout; GPIO8 and GPIO9 are exposed on the headers.
- [Bosch BME280 datasheet](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf): I2C register interface and sensor identity.
- [Adafruit BME280 product 2652](https://www.adafruit.com/product/2652): buyable I2C STEMMA QT breakout used by the example.
