# NUCLEO-WB55RG external components

The smoke needs no expansion parts. Its only board-level outputs are the
three onboard user LEDs. The profile also describes the three onboard user
buttons, but the smoke does not stimulate them.

The board's RF network, PCB antenna, ST-LINK/V2-1, USB connectors, power
selection circuitry, and second-core radio firmware are outside this model.
They are not represented as zero-answering peripherals.
