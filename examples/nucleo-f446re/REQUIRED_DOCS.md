# NUCLEO-F446RE source references

1. [ST NUCLEO-F446RE product page](https://www.st.com/en/evaluation-tools/nucleo-f446re.html)
   — active board status and board description.
2. [ST UM1724 user manual](https://www.st.com/resource/en/user_manual/dm00105823.pdf)
   — NUCLEO-F446RE target device (STM32F446RET6U), LD2 on D13/PA5, B1 on
   PC13, and default ST-LINK USART2 routing on PA2/PA3.
3. [ST STM32F446RE product page](https://www.st.com/en/microcontrollers-microprocessors/stm32f446re.html)
   — active MCU variants and product status.
4. ST RM0390, STM32F446xx reference manual — F4 RCC, GPIO, and USART2
   register map used by the smoke.
5. ST DS10693, STM32F446xC/E datasheet — package, memory, voltage, and clock
   specifications.
