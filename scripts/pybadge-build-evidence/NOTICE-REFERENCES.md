toolchain package records. The GCC-related package copyright files cover
packaging only and point to additional GCC notices. Nineteen header comment

notices or observing exception phrases does not resolve those references.

This follow-up inventories documentation listed by the **exact three installed
header-owner packages**, selecting bounded copyright/licence/COPYING candidates.

listing hash, selected/resolved documentation paths, raw capture
hashes and candidate-reference bindings are recorded. Missing same-package names
remain explicit even if another copyright candidate contains similar wording.
No unrelated host GCC package, downloaded substitute or inferred grant is used.

Acceptance requires actual hosted evidence, a separate artifact/graph/hash audit
and every enabled exact-head check. Missing named files may remain explicit
unresolved records; unsafe paths, changed inputs, malformed/oversized compressed
data fail. This does not close cross-package reference chains, common-licence
correspondence, exact package-archive provenance or legal obligations. It does not
run a compiler/linker/guest or change app pins, image admission, hardware captures,
ACKs, performance floors or store claims. Notice review and retained-byte/source
correspondence remain separate before choosing R1 replacement slices.
