# Bus Visibility Scoreboard

Generated by `bus_visibility_ratchet` (`crates/core/tests/bus_visibility.rs`).

A ✓ means this bus **produced decodable edges** on a wire-channel probe after the family's canonical bring-up and a bit-asymmetric payload: every named line in `Peripheral::line_names()` edged, and an independent decoder recovered the payload. A — means no bus instance of that kind currently produces a decodable waveform on the `from_config` path.

This is NOT a pad-binding board. Binding answers the static question "what could ever be seen here"; a green tick here means a user can actually see a waveform. Derived from live `SystemBus::from_config` builds — never hand-edited.

## Named exclusions

Chips that cannot yet produce edges for a bus are listed here with a reason — never silently skipped.

* **atmega328p**
  * I2C: AVR from_config I2C is generic type:i2c without PadLines cell
  * SPI: AVR from_config SPI is generic type:spi without PadLines cell
* **efr32mg26**
  * UART: the Efr32s2 layout models the console TX/RX byte path but captures no baud divisor (CLKDIV), so bit_time_cycles() is None and no wire waveform is narrated — there are no edges to decode
* **esp32**
  * SPI: Esp32Spi does not implement line_names()/wire_lines(); pad bindings exist but the wire channel is unpublished on this model
* **esp32s3**
  * I2C: esp32s3.yaml is an address-map stub; from_config has no S3 I2C model
  * SPI: esp32s3.yaml is an address-map stub; from_config has no S3 SPI model
  * UART: esp32s3.yaml is an address-map stub; from_config has no S3 UART model
* **esp32s3-zero**
  * I2C: esp32s3-zero.yaml inherits the S3 address-map stub
  * SPI: esp32s3-zero.yaml inherits the S3 address-map stub
  * UART: esp32s3-zero.yaml inherits the S3 address-map stub
* **mkw41z4**
  * I2C: Kinetis I2C publishes no line_names / wire_lines (honest empty)
  * SPI: no edge bring-up path for Kinetis DSPI in this gate yet
  * UART: no edge bring-up path for Kinetis LPUART in this gate yet
* **nrf5340**
  * I2C: nRF5340 serial bank not yet edge-gated on from_config
  * SPI: nRF5340 serial bank not yet edge-gated on from_config
  * UART: nRF5340 serial bank not yet edge-gated on from_config
* **nrf54l15**
  * I2C: nRF54L15 serial bank not yet edge-gated on from_config
  * SPI: nRF54L15 serial bank not yet edge-gated on from_config
  * UART: nRF54L15 serial bank not yet edge-gated on from_config
* **rp2350**
  * I2C: rp2350 from_config bus not yet edge-gated (no line cells)
  * SPI: rp2350 from_config bus not yet edge-gated (no line cells)
  * UART: rp2350 from_config bus not yet edge-gated (no line cells)
