# Explicit analog initial state

The analog adapter retains DC operating-point initialization by default. A
circuit with an undefined DC state still fails. A disabled regulator feeding an
otherwise capacitive output is one such circuit: capacitors are open at DC, so
there is no equation that fixes the stored output charge.

A caller can instead supply a complete initial reactive state. This is a
separate numerical contract. It does not add a leakage resistor, a load, or a
voltage source to the physical circuit, and it does not fall back to an
operating point.

```yaml
config:
  initialization:
    mode: transient_state
    capacitor_voltages_v:
      C1: 0.0
    inductor_currents_a:
      L1: 0.0
```

Both maps are required. They name every parsed capacitor and inductor, including
storage elements generated by supported macros. Values are signed terminal
voltages and currents in the netlist element's direction. Names resolve without
ASCII case distinction. Keys must contain 1–256 printable ASCII bytes without
whitespace; case aliases across both maps, unknown elements, missing elements,
nonfinite values, overflowing stored energy, and more than 16,384 combined
entries fail admission. Netlist `.ic` and element `ic=` cannot be combined with
this mode. `mode: operating_point` accepts no additional fields.

## The initial solve

The solver reports an accepted solution at exactly t = 0. It does not publish an
unsolved zero vector or advance time to obtain a convenient first sample.
Capacitor voltage constraints reduce to an independent spanning basis. Equal
parallel states and consistent capacitor-only cycles are allowed; contradictory
states fail before the solve. A capacitor directly clamped by stationary
independent voltage sources adds no redundant current unknown.

Inductor branch equations prescribe the requested currents. At a node connected
only to inductors and stationary current sources, the solver first verifies
initial KCL. It then differentiates that KCL with the actual inductance matrix:
`B L^-1 B^T v = 0`. This determines the initial voltage of an open zero-current
inductor and weighted series/mutually coupled inductor cutsets without an
arbitrary voltage assignment. An inconsistent initial current, a non-positive-
definite inductance matrix, or an otherwise undefined algebraic node fails.

Temporary capacitor constraints never become parsed circuit elements. Original
voltage-source and inductor branch indices keep their meaning. The solver seeds
all intrinsic diode, BJT, MOS, and JFET charge histories from the accepted initial
terminal voltages. It then removes the temporary equations and uses the normal
backward-Euler startup step. Subsequent integration uses the selected method.
Parallel capacitor reaction currents are not reported individually at t = 0;
the first real step computes each capacitor current from its voltage change.

## Admitted source-current observations

Initial independent voltage and current waveforms must have a stationary
initial plateau. Delayed ramps are allowed; an immediate nonzero slope is not.
This requirement prevents an omitted displacement current from appearing as a
physical initial source-current observation.

The constraint solver does not implement a general differentiated charge-network
solve. It therefore refuses mixed charge-storage/ideal-voltage-source cycles.
For example, a coupling capacitor from a fixed supply to a resistor-loaded node
with another capacitor to ground needs a capacitance-weighted derivative solve.
Choosing an arbitrary constraint basis would report a source current that
changes with card order. That topology is rejected explicitly, before numerical
factorization. The check includes intrinsic semiconductor charge at the parser's
actual internal junction terminals, so a declared series resistance is retained.
It also includes VCVS and CCVS output branches. A dependent output is never
assumed stationary merely because its initial voltage is known.

A storage edge fixed directly by independent stationary sources remains
admitted. Capacitor-only parallel/cyclic redundancy remains admitted. Other
unsupported algebraic cutsets retain the normal singular-system refusal; no
hidden conductance is added to produce a result.

## Resource and result contract

The selected `max_unknowns` applies to both the physical MNA dimension and the
larger initial constraint system. The solver checks the peak count before dense
matrix allocation. The default remains 128 and the hard maximum remains 1024.
An explicit initial state can therefore require a larger declared bound than
the same physical deck's operating-point system.

World co-simulation status includes:

```json
{
  "initialization": {
    "mode": "transient_state",
    "base_unknowns": 3,
    "initialization_unknowns": 4
  }
}
```

The values come from the accepted solver, remain attached after later runtime
failures, and cannot exist for a failed constructor. `labwired test` writes the
same data in `analog_initialization`, keyed by model id. `cosim-step --json`
includes the model's `initialization` in each returned analog step. Standalone
Wasm exposes the same per-model map through fallible
`analog_initialization_status()`. Runs without analog models omit the CLI fields
and return an empty Wasm map.

A constant-supply initial-state run is not a cold battery ramp or a DC operating
point. Its chosen initial charge/current and source waveform must be recorded
with the fixture. Numerical admission and a short transient do not establish
firmware startup, protection behavior, motor operation, or hardware equivalence.

## Recorded native boundary

The source-bound five-controller circuit has 667 physical MNA unknowns. Its
complete explicit state requires 737 initial unknowns. The requested 667 bound
refuses before dense allocation. At a separately selected 737 bound, the current
individual-node inductive-cutset treatment refuses a floating motor-star path
with series ideal EMF sources. A group-level derivative treatment is a separate
follow-up; this implementation does not manufacture an initial neutral voltage.

The cold flight-controller circuit passes inventory and topology admission, then
refuses at the unpowered U11 macro's overlapping fixed headroom clamps. Its
explicit-state error identifies the initial constraint and last movement. The
op-amp power-envelope correction is separate. Neither constructor failure is a
firmware execution, a native startup pass, or a flight result.
