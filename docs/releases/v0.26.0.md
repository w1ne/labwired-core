# Release v0.26.0: Connected systems, hardware models and debugging

Core changes since v0.25.0, released on 2026-09-22.

Install the CLI with `LABWIRED_VERSION=v0.26.0` using the
[installation guide](https://github.com/w1ne/labwired-core/blob/v0.26.0/README.md#installation).

Features:

- Run connected MCU systems over GPIO, SPI, I2C, UART and timed CAN. ESP32-C3
  nodes can connect, discover services, read, write and notify through BLE GATT.
  ([#1303](https://github.com/w1ne/labwired-core/pull/1303),
  [#1362](https://github.com/w1ne/labwired-core/pull/1362),
  [#1257](https://github.com/w1ne/labwired-core/pull/1257))
- Use the Python SDK and pytest integration to drive firmware, inspect results
  and test multi-node worlds from diagrams.
  ([#1245](https://github.com/w1ne/labwired-core/pull/1245),
  [#1315](https://github.com/w1ne/labwired-core/pull/1315))
- Add CPU and board paths for PIC16/PIC18/PIC24, RV64, AArch64, Cortex-R5F,
  Renesas RX, MIPS32 and CH32V003. These are documented firmware-specific
  capabilities, not complete peripheral coverage for each family.
  ([#1432](https://github.com/w1ne/labwired-core/pull/1432),
  [#1553](https://github.com/w1ne/labwired-core/pull/1553),
  [#1567](https://github.com/w1ne/labwired-core/pull/1567),
  [#1606](https://github.com/w1ne/labwired-core/pull/1606),
  [#1608](https://github.com/w1ne/labwired-core/pull/1608),
  [#1610](https://github.com/w1ne/labwired-core/pull/1610),
  [#1611](https://github.com/w1ne/labwired-core/pull/1611),
  [#1612](https://github.com/w1ne/labwired-core/pull/1612),
  [#1698](https://github.com/w1ne/labwired-core/pull/1698))
- Expand analog device models, supply-aware MCU reset, motor winding circuits,
  routed resistance and INA219 current/voltage coupling.
  ([#1251](https://github.com/w1ne/labwired-core/pull/1251),
  [#1506](https://github.com/w1ne/labwired-core/pull/1506),

Improvements:

- Reduce idle-loop, GPIO-device and multicore scheduling work while retaining
  deterministic event boundaries. Performance remains workload-specific.
  ([#1415](https://github.com/w1ne/labwired-core/pull/1415),
  [#1767](https://github.com/w1ne/labwired-core/pull/1767),
  [#1776](https://github.com/w1ne/labwired-core/pull/1776))
- Migration: coverage source paths now include directories. Update report/editor
  mappings that expect bare filenames. Unreached branches now count in totals,
  so reported branch coverage can decrease without a test regression.
  ([#1385](https://github.com/w1ne/labwired-core/pull/1385))
- Rust integrations using GPIO-net internals must replace
  `Machine::isolate_net_pads` with `join_net_pads` and use the shared `PinPort`
  interface. Corrected pull levels, DMA timing and cycle counters can change
  old expected results; review affected baselines. See the
  [detailed changelog](https://github.com/w1ne/labwired-core/blob/v0.26.0/CHANGELOG.md).
- Optional native Cortex-A7/R5F system execution supports x86_64 Linux GNU with
  explicit native features and the `native-system` profile. It is separate from
  the default/browser engine; follow the [backend limits](https://github.com/w1ne/labwired-core/blob/v0.26.0/crates/arm-system/README.md).
- The in-core analog adapter implements a defined SPICE subset. Unsupported
  vendor-model parameters, temperature directives and control scripts can be
  accepted and ignored. Check the [supported models and limits](https://github.com/w1ne/labwired-core/blob/v0.26.0/docs/cosimulation_plugins.md#netlist-subset).
