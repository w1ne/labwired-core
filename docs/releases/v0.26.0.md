# Release v0.26.0: Connected systems, hardware models and debugging

Core changes since v0.25.0. Install with `LABWIRED_VERSION=v0.26.0` (see the
[installation guide](https://github.com/w1ne/labwired-core/blob/v0.26.0/README.md#installation))
or `pip install labwired==0.26.0`. The Windows CLI and DAP need the
[x64 Visual C++ v14 Redistributable](https://aka.ms/vc14/vc_redist.x64.exe).

Features:

- Connected MCU systems over GPIO, SPI, I2C, UART and timed CAN; ESP32-C3 nodes
  exchange BLE GATT data. Several nodes can share one analog circuit.
- Python SDK and pytest integration, including multi-node worlds from diagrams.
- Source-level stepping, call stacks, GDB watchpoints, and firmware branch
  coverage with LCOV/Cobertura export.
- New CPU and board paths: PIC16/PIC18/PIC24, RV64, AArch64, Cortex-R5F,
  Renesas RX, MIPS32, CH32V003 and nRF54L05/L10. Coverage is per documented
  board and firmware, not full peripheral coverage of each family.
- Stock Arduino cores on more boards, including Arduino Zero, Teensy 4.1,
  NUCLEO-C031C6, NUCLEO-F446RE and Arduino Mega 2560 PWM.
- Analog: SPICE-detail device models, supply-aware reset, motor windings,
  routed resistance, resistor temperature coefficients and INA219 coupling.
- New parts: STM32G0B1RE/TIOL112 IO-Link, OV3660 JPEG, LoRa register models
  (no RF air link), and more sensors, displays and LED drivers, including
  NeoPixel output from classic ESP32 RMT.

Improvements:

- Less idle-loop, GPIO-device and multicore scheduling work.
- Optional native Cortex-A7/R5F system execution on x86_64 Linux
  ([limits](https://github.com/w1ne/labwired-core/blob/v0.26.0/crates/arm-system/README.md)).

Compatibility:

- Coverage source paths now include directories, and unreached branches count
  in totals, so reported branch coverage can drop without a test regression.
- Rust users of GPIO-net internals: `Machine::isolate_net_pads` is replaced by
  `join_net_pads` and the shared `PinPort` interface.
- STM32 v2 USARTs now transmit only when CR1.UE and TE are set.
- Corrected pull levels, DMA timing and cycle counters can change old expected
  results.

Fixes:

- ESP32 IDF 5 startup, LEDC duty and Preferences/NVS writes; RP2040 flash and
  USB interrupt timing; AVR EEPROM and watchdog; servo pulse timing; AHT20
  initialization; level interrupts on STM32 SPI, EFR32 timers and the NVIC.
- The Python source distribution includes all compile-time inputs.

Known limits: the STM32G071 tier-1 SPI check is still blocked
([matrix](https://github.com/w1ne/labwired-core/blob/v0.26.0/docs/coverage/tier1-scoreboard.md)).
The in-core analog engine implements a
[SPICE subset](https://github.com/w1ne/labwired-core/blob/v0.26.0/docs/cosimulation_plugins.md#netlist-subset).

Full list: [CHANGELOG](https://github.com/w1ne/labwired-core/blob/v0.26.0/CHANGELOG.md),
[compare](https://github.com/w1ne/labwired-core/compare/v0.25.0...v0.26.0).
