# Nordic nRF54L10

The nRF54L10 is a production wireless SoC with 1 MB NVM and 192 KB RAM. This
focused LabWired model uses Nordic's nRF54L15-DK with the documented
`nrf54l15dk/nrf54l10/cpuapp` target, and narrows the simulated chip to the
application-core reset path, UARTE20, and GPIO2.

| Board path | Mapping | Smoke evidence |
|---|---|---|
| DK VCOM | UARTE20 TX P1.04 / RX P1.05 | `nRF54L10 boot OK` over EasyDMA |
| DK LED0 | GPIO2 P2.09, active high | At least 16 pin edges |

The exact profile, firmware, and reproducible command are in
[`examples/nrf54l10/README.md`](../../examples/nrf54l10/README.md). The committed
run log is [`examples/nrf54l10/evidence/logs/run_smoke.log`](../../examples/nrf54l10/evidence/logs/run_smoke.log),
and the live vendor availability record is
[`examples/nrf54l10/evidence/vendor-status.md`](../../examples/nrf54l10/evidence/vendor-status.md).

Radio, TrustZone services, RISC-V coprocessor, ADC, TWI, SPI, NFC, and other DK
I/O are omitted. This profile declares no zero-answering stubs and makes no
wireless or physical-board verification claim.
