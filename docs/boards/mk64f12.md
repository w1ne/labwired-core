# MK64F12

The **MK64FN1M0VLL12** is the Cortex-M4F MCU on the **FRDM-K64F**. See the
board page for the pin map, support matrix and validation evidence:

→ **[FRDM-K64F](frdm-k64f.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated `nxp-k6xf` onboarding report exercised
a staged descriptor with a generic UART fixture; that is not the promoted
UART-only L1 package.
