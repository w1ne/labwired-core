# STM32F405 (Feather-class)

The STM32F405RG (Cortex-M4F, 1 MB flash, 192 KB SRAM — 128 KB main declared,
64 KB CCM not modeled) reuses the shared `stm32f4` / `stm32v2` peripheral
profiles. The Adafruit Feather STM32F405 Express profile exercises its red
D13 LED (PC1) and exposed USART3 header path (PB10/PB11). It is
**simulator-smoke-validated, not hardware-validated** — no F405 board has been
on the bench.

For build/run instructions, see
[`examples/feather-f405/README.md`](../../examples/feather-f405/README.md).

## Peripherals (from chip yaml)

Same declared set as the F401 descriptor plus USART3 (RCC, GPIOA–C, USART1/2/3, I2C1,
SPI1, ADC1, TIM1/TIM2, DMA1/2, EXTI, RTC, IWDG, flash, PWR, DBGMCU with
F405 IDCODE `0x10006413`, SysTick, NVIC). F405-only instances present on
silicon but **not yet declared**: I2C2, I2C3, SPI2, SPI3, USART6,
TIM3–5, RNG, CRYP/HASH — follow-up work, tracked against RM0090.
