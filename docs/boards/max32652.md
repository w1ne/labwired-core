# MAX32652 validation status

## Current measurement (2026-11-09)

The imported MAX32652 system booted `firmware-max32652-smoke` for **100,000
instructions** and passed **7/7 smoke assertions**. The firmware runs ten
register checks and prints one letter per check; the UART0 capture is
`MAX32652 checks PPPPPPPPPP DONE`, and the summary word at 0x200FF000 is
0xA32603FF. UART1 and UART2 each print one line. LED0 (P2.25) shows 6 edges.
The result, UART capture, JUnit assertions, snapshot and build/run logs are
under
[`docs/coverage/renode-onboarding/metrics/max32652/`](../coverage/renode-onboarding/metrics/max32652/).
The EVKIT row runs the same firmware on the same chip surface
([`max32652-evkit.md`](max32652-evkit.md)).

Checks (source: `crates/firmware-max32652-smoke/src/main.rs`):

0-2. UART0/1/2 STAT reset to RX_EMPTY | TX_EMPTY (0x50).
3. GPIO0 EN and IN_EN reset to all ones.
4. GPIO2 OUT_EN_SET / OUT_SET / OUT_CLR act on the latch; OUT_SET reads 0.
5. GPIO2 IN reads the driven P2.25 pad high, then low after OUT_CLR.
6. GPIO1 P1.7 (undriven input) reads 1 with PDPU_SEL0 and 0 with PDPU_SEL1.
7. EN_CLR clears the P2.28 EN bit (alternate function); EN_SET restores it.
8. GPIO3 (0x4000B000) OUT latch round trip.
9. The last word of the 1 MiB SRAM (0x200FFFFC) holds a value.

## Declared surface

Sources: Renode `platforms/cpus/max32652.repl` (memory map, instance
bases) and the MSDK MAX32650 headers `uart_regs.h` / `gpio_regs.h` and
drivers `gpio_reva.c` / `gpio_me10.c`.

| Block | Base | Model |
|---|---|---|
| Flash 3 MiB | 0x10000000 | memory |
| SRAM 1 MiB | 0x20000000 | memory |
| uart0..uart2 | 0x40042000 / 0x40043000 / 0x40044000 | `max32650_uart`, polled |
| port0..port3 | 0x40008000 + n * 0x1000 | `gpio` profile `max32650` |

Sizes are byte counts (`3145728B`, `1048576B`): `parse_size` reads `MB` as
decimal, so `1MB` gives 1 000 000 B and the stack top faults (negative
control below).

Not declared (no model in this engine): GCR, WDT0/1, TMR0-5, TPU, I2C0/1,
ADC, SPI0-3, RTC, PWRSEQ, DMA, flash controller, caches, USB, TRNG, SDHC,
SPIXF/SPIXR/HyperBus and the external memory windows. UART and GPIO
interrupts are not modelled, so no NVIC lines are declared. The GPIO model
answers for 32 pins on port 3 (10 on silicon). GPIO reset values follow
Renode (EN and IN_EN all ones); Renode's OUT_EN reset 0x08000000 has no
second source and is not adopted.

## Negative controls

Under
[`attempt-history/max32652/`](../coverage/renode-onboarding/attempt-history/max32652/):

- old descriptor (UART0 only): BusFault at 0x40043008 (UART1 STAT), 1/7.
- `3MB` / `1MB` sizes: BusFault at 0x200FEFFC on the first stack push, 0/7.
- no GPIO ports: BusFault at 0x40008000 (GPIO0 EN), 1/7.
