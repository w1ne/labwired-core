# CC2538SF53

The **CC2538SF53** is the Cortex-M3 IEEE 802.15.4 MCU on the **TI CC2538DK**.
See the board page for the pin map, support matrix and validation evidence:

→ **[CC2538DK](cc2538dk.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated `cc2538` onboarding report exercised
a staged descriptor with a generic UART fixture on a placeholder memory map;
that is not the promoted UART+LED L1 package.
