# Imported STM32F103 onboarding smoke

The imported system profile is bounded to a Cortex-M3, 64 KiB flash, 20 KiB
SRAM, RCC, GPIOA and USART2. These windows match the common STM32F103C8
density. Other STM32F1 variants and peripherals are outside this profile.

The exact imported-system smoke ran the Cortex-M3 firmware for 200,000
instructions. It emitted `OK` through USART2, observed at least one GPIOA pin 5
edge while the firmware toggled PA5, and stopped at the configured
instruction limit. The JUnit record passed all three smoke assertions.
The run assumes an ideal power rail; it does not exercise power-on or
brown-out reset behavior.

Evidence, including the result, UART output, snapshot, JUnit report and build/run
logs, is in
[`docs/coverage/renode-onboarding/metrics/stm32f103/`](../coverage/renode-onboarding/metrics/stm32f103/).

This is a local LabWired CLI smoke against the imported manifest. It does not
validate the whole STM32F103 platform, the unlisted peripherals, Renode
equivalence or physical hardware.
