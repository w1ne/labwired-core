# Allwinner A20 imported profile

## Measured profile

The imported Renode [`a20.repl`](https://github.com/renode/renode/blob/master/platforms/cpus/a20.repl)
describes the A20's Cortex-A7 platform, including DDR at `0x40000000` and UART0
at `0x01C28000` with `wideRegisters: true`. LabWired's onboarding profile is
narrowed to one Cortex-A7 PE, a 64 KiB DDR aperture at that base, and UART0's
polled TX path. The 64 KiB aperture is a simulator limit for this smoke, not the
physical DDR capacity. The profile does not expose the boot ROM, internal SRAM,
second PE, GIC, generic timer, MMC, USB, or UART1–UART7.

UART0 uses the engine's existing 32-bit, 4-byte-stride 16550 register map to
match Renode's `wideRegisters: true`; this does not identify the A20 UART as a
DesignWare device. Interrupts, baud/framing timing, and RX are outside the
smoke.

## Smoke evidence

The committed A32 fixture is linked at `0x40000000`, injected directly into the
DDR aperture, writes `A20 A7 UART SMOKE` to UART0's TX register, and then spins.
It ran **100,000 Cortex-A7 instructions** and passed the UART banner and bounded
`max_steps` assertions (JUnit: 3 cases, 0 failures). This exercises direct ELF
execution and the imported UART0 TX path; it does not boot through the A20 ROM
or prove the rest of the SoC.

The exact system manifest is `configs/systems/onboarding/a20.yaml`. The build
recipe is [`scripts/build_a20_a7_uart_smoke.sh`](../../scripts/build_a20_a7_uart_smoke.sh).
Per-target metrics, JUnit, UART output, simulator result, snapshot, and logs are
under `docs/coverage/renode-onboarding/metrics/a20/`. The first CLI build attempt
failed because bindgen could not find `stdbool.h`; its metric and log are
preserved under `docs/coverage/renode-onboarding/attempt-history/a20/`.

This is local CLI simulation evidence for the smoke assertions, not whole-A20
coverage, Renode equivalence, or hardware confirmation. The current global
inventory is **245 descriptors, 212 booted and smoke-passing, 31 not run, and 2
run failures**; see the [generated scoreboard](../coverage/renode-onboarding-scoreboard.md).
