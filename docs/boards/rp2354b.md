# RP2354B

The RP2354B is the RP2350 die in the QFN80 package with 2 MB of flash
stacked in the package (RP2350 datasheet, Chapter 1, Table 1). It is
onboarded as its own descriptor, not as an alias of the 30-GPIO
[`rp2350`](rp2350.md) profile: same register blocks and models, with the
package-dependent ones on their QFN80 profiles. It is **smoke-validated,
not hardware-validated**.

## What differs from `rp2350`

| Block | RP2354B (QFN80) | Source |
|-------|-----------------|--------|
| Flash | 2 MiB at 0x10000000 | datasheet Table 1 |
| SYSINFO.PACKAGE_SEL | 0 (QFN80) | pico-sdk rp2350 `sysinfo.h` |
| IO_BANK0 (`profile: rp2350b`) | GPIO0..47 CTRL live; INTR0..5, PROC0_INTE/INTF/INTS0..5, IRQSUMMARY_PROC0_SECURE0/1 cover all 48 pads | pico-sdk rp2350 `io_bank0.h`, `platform_defs.h` (`NUM_BANK0_GPIOS` 48) |
| SIO (`profile: rp2350b`) | GPIO32..47 are bits [15:0] of `GPIO_HI_IN/OUT/OE` and their SET/CLR/XOR twins; the GPIO coprocessor reaches them through the same words | pico-sdk rp2350 `sio.h` |
| ADC (`profile: rp2350b`) | inputs 0..7 = GPIO40..47, temperature sensor = input 8; `CS.AINSEL` [15:12], `CS.RROBIN` [24:16]; FIFO IRQ 35 | pico-sdk rp2350 `adc.h`, `platform_defs.h`, `intctrl.h` |

Everything else (clocks/resets, UART, SPI, I2C, PWM, TIMER0, watchdog, DMA,
PIO, boot ROM window, BOOTRAM, USBCTRL, DCP and GPIO coprocessors) is the
`rp2350` descriptor unchanged; see [RP2350](rp2350.md) for what those models
cover.

## Not modelled

* The `rp2350` gaps: POWMAN/TICKS/TRNG/SHA-256/OTP/HSTX, QMI programming,
  TrustZone, Hazard3, the second M33 core.
* RP2350 PIO extensions, including `GPIOBASE`: PIO reaches GPIO0..31 only.
* The QSPI and USB bits of the SIO `GPIO_HI_*` words read 0.
* GPIO32..47 have no register-address binding: a device or `pins:` lookup
  that needs `(GPIO_OUT address, bit)` for them is refused, because they are
  not bits of the 32-bit `GPIO_OUT` word. The pad interface (`sio:47`,
  logic capture, world nets) reaches all 48 pads.
* `analog_pins`: the ADC inputs are there for firmware, but no GPIO40..47
  analog-pin labels are declared yet.
