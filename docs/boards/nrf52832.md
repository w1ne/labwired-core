# nRF52832

The Nordic nRF52832 (Cortex-M4F, 512 KB flash, 64 KB SRAM, 2.4 GHz radio)
is a Tier 1 LabWired target. The chip yaml declares the Cortex-M4F core,
UART0, GPIO P0, CLOCK, TIMER0–2, TWI0/TWI1, SPI2, RTC0/RTC1, WDT, SAADC,
PWM0, NVMC, FICR, UICR, and the RADIO register block.

This page is a hand-maintained snapshot. For the authoritative per-block
status see the [chip conformance scoreboard](../coverage/chip-conformance.md)
(level · modelled peripherals · register-match vs silicon) and the
[tier-1 matrix](../coverage/tier1-scoreboard.md) (per-peripheral pass/fail).

## Peripherals declared (from chip yaml)

| Peripheral | Base       | Notes                                                   |
|------------|------------|---------------------------------------------------------|
| Cortex-M4F | —          | Thumb-2 + VFPv4 single-precision                        |
| UART0      | 0x40002000 | `nrf52` profile — Nordic register layout, not PrimeCell |
| TIMER0     | 0x40008000 | IRQ 8; 16 MHz base clock, 4 CC                           |
| TIMER1     | 0x40009000 | IRQ 9; same model                                        |
| TIMER2     | 0x4000a000 | IRQ 10; same model                                       |
| GPIO P0    | 0x50000000 | nRF GPIO register layout                                 |
| CLOCK      | 0x40000000 | HFCLK/LFCLK task and event registers                     |
| TWI0/TWI1  | 0x40003000 / 0x40004000 | I²C models                                  |
| SPI2       | 0x40023000 | `nrf52_spim` layout                                      |
| RTC0/RTC1  | 0x4000b000 / 0x40011000 | 24-bit RTC; RTC1 drives Arduino `millis()`  |
| WDT        | 0x40010000 | Watchdog                                                 |
| SAADC      | 0x40007000 | ADC                                                      |
| PWM0       | 0x4001c000 | PWM                                                      |
| NVMC       | 0x4001e000 | Flash controller                                         |
| FICR, UICR | 0x10000000 / 0x10001000 | Factory and user configuration              |
| RADIO      | 0x40001000 | Register block; radio traffic is not simulated           |

TIMER0–2 count their 16 MHz base clock, not the 64 MHz core clock. The
`nrf_timer_base_clock` gate in `crates/core/tests/nrf/` checks the
descriptors and the captured counter.

## Not declared

POWER, PPI, RNG, TEMP, ECB, CCM, AAR, GPIOTE, SPI0/1, TWIM/TWIS, I2S,
PDM, and the EasyDMA infrastructure. Firmware that touches any of these
registers hits `MemoryAccessViolation` or stalls in a polling loop. See
[`docs/getting_started_firmware.md`](../getting_started_firmware.md).

## Roadmap notes

nRF52832 is a Tier 1 target (see
[`docs/coverage_scoreboard.md`](../coverage_scoreboard.md)). Closing the gap
to a full Tier 1 model requires at minimum: POWER, PPI, GPIOTE, and a
behavioural RADIO. The hardware-validation playbook to follow once
peripherals are added is
[`docs/boards/nucleo-l476rg.md`](nucleo-l476rg.md).
