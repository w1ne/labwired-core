# STM32F401 (NUCLEO-F401RE)

The NUCLEO-F401RE system uses the exact `stm32f401re` chip descriptor and the
shared F401 peripheral model. Its onboarding smoke emits a USART2 marker and
records GPIOA5 output edges. The F401 Tier-1 fixture also drives all twelve
rubric classes (see the [firmware-exercise matrix](FIRMWARE_EXERCISE_MATRIX.md)).
These are simulator results; there is no F401 silicon capture.

> **Timer input capture (2026-09-27):** the shared family descriptor's TIM1-5
> and TIM9-11 declare
> `input_capture: stm32f4`. A pad muxed to `TIMx_CHn` (DS9716 AF1/AF2/AF3)
> feeds the channel: CCxS TI1/TI2/TRC, ICxF filter, ICxPSC, CCxP/CCxNP
> (rising/falling/both), CCRx latched at the edge cycle with CCxIF/CCxOF and
> the CCx interrupt, and PWM-input mode (slave reset on TI1FP1). Proven by
> register-level firmware in `crates/core/tests/timer_input_capture.rs`
> (HC-SR04 echo width; frequency/duty meter). Not modelled: the CCxDE DMA
> request (the STM32 DMA request map is not modelled for timers), the
> gated/trigger/external-clock slave modes, ITRx/ETR triggers, and the
> 2-3-cycle input resynchroniser delay of silicon.

> **Peripheral scope:** the F401 descriptor includes modeled I2C1, SPI1,
> DMA1/2, TIM1-4, ADC1, IWDG, RTC, PWR, FLASH, USART1/2, GPIOA/B/C and the
> system blocks listed below. The NUCLEO-F401RE smoke exercises only USART2
> output and GPIOA5. No external I2C/SPI devices are attached by this system.

> **Package variant:** the STM32F401CDU6 (384 KB flash, 96 KB SRAM) has its own
> chip descriptor
> ([`configs/chips/stm32f401cdu6.yaml`](../../configs/chips/stm32f401cdu6.yaml))
> and a PR-run gate
> (`firmware_survival::test_stm32f401cdu6_demo_survival`, asserting `OK` over
> USART2). It shares this model.

For build/run instructions, see
[`examples/nucleo-f401re/README.md`](../../examples/nucleo-f401re/README.md).

## Not declared on this F401RE descriptor

The exact F401RE descriptor includes I2C1, SPI1, DMA1/2, TIM1-4, ADC1, IWDG,
RTC, PWR, FLASH, USART1/2, GPIOA/B/C, and system blocks. It does not declare
I2C2/I2C3, SPI2/SPI3/SPI4/SPI5, TIM5/TIM9/TIM10/TIM11, WWDG, CRC, USB OTG FS,
SDIO, or USART6. The onboarding smoke exercises only USART2 and GPIOA5.

The descriptor contains no explicit `type: stub` windows. Firmware accesses
to absent blocks fault as unsupported; they do not read back zero from a
placeholder window. See [`docs/getting_started_firmware.md`](../getting_started_firmware.md)
for the diagnosis pattern.

## Roadmap notes

F401 is a Tier 1 target (see
[`docs/coverage_scoreboard.md`](../coverage_scoreboard.md)). Silicon parity
remains future work. The hardware-validation playbook is
[`docs/boards/nucleo-l476rg.md`](nucleo-l476rg.md) — six survival tests
asserting byte-for-byte UART parity with real silicon across UART, SPI,
I²C, ADC, DMA, demo paths.
