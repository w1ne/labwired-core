# PIC32MZ2048EFM144

The **PIC32MZ2048EFM144** is the PIC32MZ EF MCU (MIPS32 M5150 core with FPU,
2 MiB flash, 512 KiB RAM, 144-pin TQFP) on the **Microchip Curiosity
PIC32MZ EF 2.0** development board. See the board page for the support matrix
and validation evidence:

→ **[Curiosity PIC32MZ EF 2.0](curiosity-pic32mz-ef.md)**
