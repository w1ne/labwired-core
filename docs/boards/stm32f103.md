# STM32F103 (Bluepill / demo-blinky)

The STM32F103C8 (Cortex-M3, 64 KB flash, 20 KB SRAM in the popular C8
package; this chip yaml advertises 1 MB / 128 KB to fit the full F103xE
memory map) is LabWired's reference Cortex-M3 target. It is the chip used
by [`examples/demo-blinky/`](../../examples/demo-blinky/README.md), the
canonical example for **attaching an external device model (TMP102) over
I²C**.

For build/run instructions, see
[`examples/demo-blinky/README.md`](../../examples/demo-blinky/README.md).

## Blue Pill BME280 smoke profile

| Peripheral | Base       | Status       | Notes                                                |
|------------|------------|--------------|------------------------------------------------------|
| Cortex-M3  | —          | ✅ modeled   | Thumb-2, no FPU                                      |
| SysTick    | 0xE000E010 | ✅ modeled   | Required system timer path                           |
| RCC        | 0x40021000 | ✅ modeled   | F1 clock-enable registers                             |
| GPIOA      | 0x40010800 | ✅ modeled   | PA9 USART1 transmit                                   |
| GPIOB      | 0x40010C00 | ✅ modeled   | PB6/PB7 I2C1 SCL/SDA                                  |
| GPIOC      | 0x40011000 | ✅ modeled   | PC13 active-low onboard LED                          |
| USART1     | 0x40013800 | ✅ modeled   | UART marker, captured by simulator                   |
| I²C1       | 0x40005400 | ✅ modeled   | Reads BME280 chip ID `0x60` at address `0x77`        |

This is the **narrow** profile in
[`configs/chips/stm32f103c8-bluepill-bme280-smoke.yaml`](../../configs/chips/stm32f103c8-bluepill-bme280-smoke.yaml),
not the broader family descriptor. It includes no explicit zero-answer
peripheral windows. The family descriptor at `configs/chips/stm32f103.yaml`
models additional blocks and retains explicit `stub` windows for USB and
backup registers; neither is included in this board profile.

SPI, timers, ADC, CAN, USB, DMA, I2C2, USART2/3, AFIO, and EXTI are outside the
narrow profile. Firmware that accesses registers outside declared windows
will fault or stall, depending on the access path. See
[`docs/getting_started_firmware.md`](../getting_started_firmware.md) for the
diagnosis pattern.
