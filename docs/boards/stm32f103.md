# STM32F103 (Bluepill / demo-blinky)

The STM32F103C8 (Cortex-M3, 64 KB flash, 20 KB SRAM) is LabWired's reference
Cortex-M3 target and is used by [`examples/demo-blinky/`](../../examples/demo-blinky/README.md), the
canonical example for **attaching an external device model (TMP102) over
I²C**.

For build/run instructions, see
[`examples/demo-blinky/README.md`](../../examples/demo-blinky/README.md).

## Model boundaries

The chip config also declares SPI1/2, timers, ADC, bxCAN, RTC, IWDG, and PWR.
The USB device and BKP windows are zero-answering stubs; WWDG is an inert
model. The Blue Pill board smoke does not exercise those paths. For the
peripheral-by-peripheral firmware evidence, see the
[`FIRMWARE_EXERCISE_MATRIX`](FIRMWARE_EXERCISE_MATRIX.md#stm32f103).
