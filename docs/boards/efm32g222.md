# EFM32G222 Renode onboarding smoke

**Architecture:** ARM Cortex-M3.

The imported execution profile at `configs/chips/onboarding/efm32g222.yaml`
contains the 128 KiB flash and 16 KiB RAM map plus the model-backed USART0
window at `0x4000c000`. Other imported peripheral entries were omitted because
this engine has no behavioral models for them.

## Current evidence

The exact imported-system smoke in `examples/renode-onboarding/efm32g222-smoke.yaml`
ran 100,000 Cortex-M3 instructions and passed two assertions: UART output
contained `EFM32G222 USART0 smoke`, and execution stopped at the configured
`max_steps` limit.

Build logs, UART output, JUnit assertions, simulator result, and snapshot are in
[`docs/coverage/renode-onboarding/metrics/efm32g222/`](../coverage/renode-onboarding/metrics/efm32g222/).
The full imported inventory scoreboard is
[`docs/coverage/renode-onboarding-scoreboard.md`](../coverage/renode-onboarding-scoreboard.md).

This is repository CLI smoke evidence for the modeled CPU, memory, and USART0
path. It is not full EFM32G222 peripheral coverage, hosted `labwired_verify`
model verification, or hardware confirmation.
