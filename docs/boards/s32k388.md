# S32K388

The **NXP S32K388** is the S32K3 automotive MCU on the **NXP
S32K388EVB-Q289**. Only its boot core, CM7_0 (Cortex-M7), is modelled. See
the board page for the pin map, support matrix and validation evidence:

→ **[S32K388EVB-Q289](s32k388-evb.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated `nxp-s32k388` / `nxp-s32k388evb`
onboarding reports exercised staged descriptors with a generic UART fixture;
that is not the promoted LPUART+LED L1 package.
