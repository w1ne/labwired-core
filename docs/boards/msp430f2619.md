# MSP430F2619 onboarding scope

**Status: not run.** LabWired has no MSP430 CPU implementation or MSP430 ELF
architecture support. This descriptor has not booted firmware and has no smoke
pass. The earlier `structural-ok` result checked that files and memory bounds
were present; it did not validate instruction execution or peripherals.

The imported chip profile previously declared `arch: arm`, which would route an
MSP430 MCU through the wrong CPU family. The profile now declares `arch: unknown`
so the engine refuses to simulate it, and it no longer lists the zero-answering
`msp430f2xxx_mpy` stub. The imported flash and RAM windows remain recorded as
static memory-map data; they have not been exercised by a CPU.

The current scoreboard records `msp430f2619` as `not_run` with the reason that a
real MSP430 CPU core is missing. The other MSP430 imports also remain
unmeasured. Bringing this family into executable coverage requires a real CPU
core and architecture support, a substantial separate project; adding a
peripheral stub cannot make these platforms boot.
