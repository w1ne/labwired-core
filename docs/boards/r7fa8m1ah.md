# R7FA8M1AH

The **R7FA8M1AH** is the RA8M1 Cortex-M85 MCU on the **Renesas EK-RA8M1**.
See the board page for the pin map, support matrix and validation evidence:

→ **[EK-RA8M1](ek-ra8m1.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated `renesas-ek_ra8m1` onboarding report
exercised a staged descriptor with a generic UART fixture on a placeholder
memory map; that is not the promoted UART+LED L1 package.
