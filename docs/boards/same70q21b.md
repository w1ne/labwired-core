# ATSAME70Q21B

The **ATSAME70Q21B** is the SAM E70 Cortex-M7 MCU on the **Microchip SAM E70
Xplained**. See the board page for the pin map, support matrix and validation
evidence:

→ **[SAM E70 Xplained](sam-e70-xplained.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated `sam_e70` onboarding report
exercised a staged descriptor with a generic UART fixture on a placeholder
memory map; that is not the promoted USART+LED L1 package.
