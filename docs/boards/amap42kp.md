# AMAP42KP

The **AMAP42KP-KBR** (Ambiq Apollo4 Plus) is the Cortex-M4F SoC on the
**Ambiq Apollo4 Plus EVB** (AMAP4PEVB). See the board page for the pin map,
support matrix and validation evidence:

→ **[Apollo4 Plus EVB](apollo4p-evb.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated `ambiq-apollo4` onboarding report
exercised a staged descriptor with a generic UART fixture on a placeholder
memory map; that is not the promoted UART+LED L1 package.
