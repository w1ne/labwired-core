# STM32L552

The **STM32L552ZET6Q** is the Cortex-M33 MCU on the **NUCLEO-L552ZE-Q**. See
the board page for the pin map, support matrix and validation evidence:

→ **[NUCLEO-L552ZE-Q](nucleo-l552ze-q.md)**

This part-level page exists so the model-rating table links to the promoted
board package. The earlier auto-generated report exercised the staged
Renode-derived `configs/chips/onboarding/stm32l552.yaml` with a generic UART
fixture; that is not the promoted L1 package, and its "0 stubs" score was
misleading because the import dropped RCC, flash, EXTI, ADC, FDCAN and RNG.
