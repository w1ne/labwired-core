# STM32F767 (NUCLEO-F767ZI)

The STM32F767ZI (Cortex-M7, 2 MB flash, 512 KB SRAM) is onboarded as a
descriptor-level derivative of the F4 lane: it reuses the shared `stm32f4` /
`stm32v2` peripheral profiles for RCC/GPIO/USART/SPI/timers/DMA/EXTI/RTC/
IWDG/flash/PWR, and the `stm32l4` profile for I2C (the F7 I2C is the modern
v2 IP, not the F1/F4 legacy block). Its part-specific RCC/GPIO/timer/I2C/SPI/
ADC/watchdog/RTC smoke is run from source by the onboarding lane. It is
**simulation-smoke-tested, not hardware-validated** — no F767 board has been
on the bench.

For build/run instructions, see
[`examples/nucleo-f767zi/README.md`](../../examples/nucleo-f767zi/README.md).

## Board-level smoke signals

| Signal | MCU pin | Board route | Smoke coverage |
|---|---|---|---|
| ST-LINK virtual COM TX/RX | PD8 / PD9 (USART3 AF7) | On-board VCP | UART setup and transcript |
| User LED LD1 | PB0 | On-board LED | GPIO set/clear |
| User button B1 | PC13 | On-board button | Declared in `board_io`, not read by this smoke |

## Modeled (from chip yaml)

RCC (F4 profile), GPIO A–K, USART1/2/3/6, I2C1–4 (v2/`stm32l4` profile),
SPI1–3, TIM1/TIM2, ADC1, DMA1/2, EXTI (24 lines), RTC, IWDG, flash, PWR,
DBGMCU (IDCODE `0x10006451`), SysTick, NVIC.

## Explicitly not modeled

F7-only RCC registers (PLLSAICFGR, DCKCFGR1/2 — peripheral clock muxing),
Ethernet, LTDC/DMA2D, CAN, USB OTG FS/HS, SAI, QSPI, MDIOS, JPEG, DFSDM,
FMC, SDMMC, ART accelerator reconfiguration. These blocks are omitted from
the chip descriptor; they are not declared as zero-answering peripherals.
The onboarding system has no `type: stub` windows. See the
[`vendor-status receipt`](../../examples/nucleo-f767zi/evidence/vendor-status.md)
for the live buyability check and [`validation runbook`](../../examples/nucleo-f767zi/VALIDATION.md)
for the exact smoke boundary.
