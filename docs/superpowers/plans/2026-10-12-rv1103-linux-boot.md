# RV1103 Linux direct boot implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Root owns commits and merges. Steps use checkbox syntax for tracking.

**Goal:** Run a pinned, real Linux kernel and static userspace with timer-driven wakeups through LabWired's RV1103 physical Bus.

**Architecture:** The optional native system CPU connects to a bus-owned ARM fabric. GIC distributor/CPU-interface devices share one controller; the architectural timer shares its PPI levels and synchronizes from the bus clock. The normal Machine scheduler remains authoritative, including zero-retirement WFI and IRQ transitions.

**Tech Stack:** Existing Rust core, embedded tlib, GICv2, DW APB UART, ARM zImage/DTB, deterministic newc initramfs, Alpine ARMv7 binaries, Python artifact preparation, dtc.

## Task 2: GIC, architectural timer and UART2

Create `crates/core/src/peripherals/armv7/{mod.rs,gic.rs,timer.rs,dw_uart.rs}` and tests `crates/core/tests/rv1103_devices.rs`; wire optional Armv7Fabric through the existing bus fabric. New peripheral types implement the existing console/RX attachment methods.

- [x] Write red tests for GIC enable/priority/acknowledge/EOI/deassert, timer compare/control/mask/IRQ deadline, and UART DLAB/FIFO/IER/IIR/LSR, using actual register widths.
- [x] Implement one CPU GICv2 with 256 INTIDs. Distributor CTLR/TYPER/IIDR, group/enables/pending/active bitmap sets and clears, priority/targets/config bytes, SGIR and ID registers; CPU interface CTLR/PMR/BPR/IAR/EOIR/RPR/HPPIR and ID registers. Source level persists across EOI; active sources do not repeatedly acknowledge. Respect priority mask and current active priority. Group0 FIQEn routes to FIQ; normal enabled interrupt groups route to IRQ. No virtualization/multicore claim.
- [x] Implement 24 MHz CP15 generic timer owner. Decode MRC/MCR fields `(opc1,CRn,CRm,opc2)` and MRRC/MCRR `(opc1,CRm)`. Support CNTFRQ, CNTKCTL, CNTP/CNTV TVAL/CTL/CVAL, CNTPCT/CNTVCT and CNTVOFF. Signed TVAL, writable ENABLE/IMASK and derived ISTATUS are required. Unknown external CP15 accesses return errors. Counter conversion uses absolute u128 arithmetic from modeled CPU ticks, not host time. Expose the nearest unmasked enabled compare deadline in CPU ticks.
  Initial reduction: CNTKCTL retains EL0 access, event direction and index fields, but enabling EVNTEN returns an explicit error before mutation. The pinned kernel enables CONFIG_ARM_ARCH_TIMER_EVTSTREAM; the supported Linux early parameter `clocksource.arm_arch_timer.evtstrm=0` therefore disables its WFE event stream in the reduced fixture. Generic timer IRQs, WFI and guest sleep remain required.
- [x] `SystemBus::set_current_cycle` updates the ARM counter and GIC INTID29 for the direct-boot secure physical timer and INTID27 for the virtual timer. The vendor-derived minimal DT advertises only secure/nonsecure physical PPI13/14, so the tested Linux guest selects INTID29. Do not misroute CNTV to the nonsecure physical INTID30. Independent TrustZone timer banks remain outside this slice. The planner includes its deadline, and native WFI idle budget stops there. Timer register writes end the current execution window so new deadlines cannot be overrun.
- [x] Implement DW UART2 at ff4c0000 (reg-shift2/mmio32) with divisor latch, RX FIFO, THRE/TEMT, IER/IIR, FCR clear, line/modem/scratch registers and RX injection; console bytes pass through existing sinks. Source SPI27 means GIC INTID59. Do not use a UART stub that emits divisor bytes as console output. Unimplemented DMA/modem timing is disclosed.
- [x] Run `cargo test -p labwired-core --features qemu-arm-system,event-scheduler --test rv1103_devices --test qemu_arm_system` under a bounded unwind test profile. Review both correctness and default-path regressions.
