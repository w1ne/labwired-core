# INA260

TI INA260 current / voltage / power monitor with an integrated 2 mΩ shunt.

!!! tip "Live catalog"
    Prefer `labwired_describe` with the catalog id over guessing pins or addresses.

## Support matrix

| Behavior | Status | Notes |
|----------|--------|-------|
| Manufacturer ID 0x5449 / Die ID 0x2270 | ✅ |  |
| Configuration POR 0x6127, write mask, RST | ✅ | D14:D12 fixed 110 |
| Current (1.25 mA/LSB) and bus voltage (1.25 mV/LSB) | ✅ | Two's-complement current |
| Power (10 mW/LSB) | ✅ | |Current| × Bus / 6400 in counts; reproduces Table 1 |

| Averaging, conversion-time settings, alerts, power-down | ❌ | Not modelled |

## Stimulus

Host inputs: `bus_voltage` (V), `current` (A).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "ina260"
       type: "ina260"
       connection: "i2c0"   # the bus id your chip system uses
   ```
2. Agent: `labwired_list` → `labwired_describe id=ina260` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test everyday_sensor_set` — IDs, Configuration 0x6127, and 800 / 4000 / 500 counts at 1 A / 5 V. The same file's negative control proves the check fails against a part that answers only 0x00 or only 0xFF.

## Limitations

- The 15 A continuous rating and shunt thermal limits are not enforced by the twin.

See the YAML header for the full datasheet trace and every named approximation.
