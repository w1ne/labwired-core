# MCP3008

Microchip MCP3008 8-channel 10-bit SAR ADC with SPI interface (single-ended and differential).

!!! tip "Live catalog"
    Prefer `labwired_describe` with the catalog id over guessing pins or addresses.

| Behavior | Status | Notes |

## Stimulus

Host inputs: `ch0_mv` … `ch7_mv`, `vref_mv` (millivolts).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "mcp3008"
       type: "mcp3008"
       connection: "spi1"
       config:
         cs_pin: "PA4"
   ```
2. Agent: `labwired_list` → `labwired_describe id=mcp3008` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test parts_batch5` — CH0 → 512, CH5 → 310, CH0−CH1 differential → 256, and the clamp; `mcp3008_tracks_stimulus_vref_and_lsb_first_repeat` covers VREF, full scale and the LSB-first repeat. The same file's negative control proves the check fails against a stand-in that answers only 0x00 or only 0xFF.

## Limitations

- The start bit must be bit 0 of the first byte (Figure 6-1); the `0x18 | ch` five-bit form returns zeros.
- Inputs are integer millivolts; the result is the ideal transfer function.

See the YAML header for the full datasheet trace and every named approximation.
