# ACS712 current sensor

`acs712` models the **5 A ACS712ELCTR-05B** with its typical 25 °C transfer.
The `current` stimulus is in amperes, from −5 to +5, initially zero.
OUT is `VCC/2 + 0.185 V/A × current` at a 5 V supply. Both offset and
sensitivity scale with the supplied rail. The real MCU ADC model converts
the resulting millivolts; a stimulus never writes ADC result registers.

```yaml
external_devices:
  - id: current
    type: acs712
    connection: adc
    config: {channel: 1, supply_mv: 5000}
```

On an Uno this puts OUT on ADC1/A1. The hosted catalog module has VCC, GND
and OUT signal pads. Its high-current conductor is a stimulus source in this
model, not an automatic series connection to a motor winding.

| Modeled | Boundary |
| --- | --- |
| Signed current and ratiometric output | 5 A variant only; 20 A/30 A variants have different sensitivity |
| ADC voltage routing and firmware conversion | Millivolt quantization; no sensor noise, bandwidth or thermal drift |
| Range validation | Inputs outside −5…+5 A are refused |

`desk_controller_inputs` sweeps the signed transfer at 4.5/5.0/5.5 V and
executes Arduino `analogRead` for 0.5 A, 2.5 A and −2.5 A. This is model
validation against the published transfer, not a physical sensor capture.

Source: [Allegro ACS712 datasheet](https://www.allegromicro.com/-/media/files/datasheets/acs712-datasheet.pdf).
