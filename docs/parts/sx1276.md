# SX1276

Semtech SX1276 LoRa transceiver over SPI — the LoRa register page, RSSI/SNR from stimulus, TxDone. **No RF air link.**

!!! tip "Live catalog"
    Prefer `labwired_describe` with the catalog id over guessing pins or addresses.

## Stimulus

Host inputs: `rssi_dbm`, `packet_rssi_dbm` (dBm), `snr_db` (dB).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "sx1276"
       type: "sx1276"
       connection: "spi1"
       config:
         cs_pin: "PA4"
   ```
2. Agent: `labwired_list` → `labwired_describe id=sx1276` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test parts_batch5` — RegVersion, the LoRa-page reset values and the RSSI word in LoRa mode; `sx1276_tx_raises_txdone_and_irq_flags_clear_on_one` covers the LF offset, SNR, write-1-to-clear and TX. The same file's negative control proves the check fails against a stand-in that answers only 0x00 or only 0xFF.

## Limitations

- Nothing is ever received: RX never sets RxDone and the 256-byte FIFO is not modelled.
- The FSK/OOK register page is not presented — use `rfm95` for an FSK driver.
- DIO0 is not driven, so an interrupt-driven TX-done wait does not complete; a polling one does.

See the YAML header for the full datasheet trace and every named approximation.
