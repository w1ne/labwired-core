# PCF8575

16-bit quasi-bidirectional I²C I/O expander — the 16-bit PCF8574.

!!! tip "Live catalog"
    Prefer `labwired_describe` with the catalog id over guessing pins or addresses.

| Behavior | Status | Notes |

## Stimulus

Host inputs: `port` (0–65535, P07–P00 in the low byte).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "expander"
       type: "pcf8575"
       connection: "i2c0"   # the bus id your chip system uses
       config:
         p00_pin: "PC0"
         p17_pin: "PC1"
   ```
2. Agent: `labwired_list` → `labwired_describe id=pcf8575` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test everyday_sensor_set` — power-on 0xFF 0xFF, and a written pair 0x34 0x12 read back as 34 12 34 12. The same file's negative control proves the check fails against a part that answers only 0x00 or only 0xFF; `pcf8575_tracks_stimulus` covers pairing, odd bytes and the 16 pad drives.

## Limitations

- The datasheet says every transfer must be an even number of bytes. A trailing odd byte is dropped at STOP and never reaches the pins.

See the YAML header for the full datasheet trace and every named approximation.
