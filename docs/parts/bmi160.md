# BMI160

Bosch BMI160 6-axis IMU (accelerometer + gyroscope + temperature) over I²C.

!!! tip "Live catalog"
    Prefer `labwired_describe` with the catalog id over guessing pins or addresses.

| Aspect | Status |

| Bus | I²C |
| Address | 0x68 (SDO→GND); 0x69 SDO→VDDIO |

## Stimulus

Host inputs: `accel_x/y/z` (g), `gyro_x/y/z` (°/s), `temperature` (°C).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "bmi160"
       type: "bmi160"
       connection: "i2c1"
   ```
2. Agent: `labwired_list` → `labwired_describe id=bmi160` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test parts_batch5` — CHIP_ID, suspended data/temperature, then CMD 0x11/0x15 and 1 g on Z; `bmi160_scales_with_range_and_softreset_restores_defaults` covers range scaling, the temperature gate and softreset. The same file's negative control proves the check fails against a stand-in that answers only 0x00 or only 0xFF.

## Limitations

- drdy bits do not clear on a data read; data is always fresh.
- PMU switch times (Table 24) are not modelled.

See the YAML header for the full datasheet trace and every named approximation.
