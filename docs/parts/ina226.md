## Support matrix

| Behavior | Status | Notes |

## Stimulus

Host inputs: `bus_voltage` (V), `current` (A through 0.1 Ω).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "ina226"
       type: "ina226"
       connection: "i2c0"   # the bus id your chip system uses
   ```
2. Agent: `labwired_list` → `labwired_describe id=ina226` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test everyday_sensor_set` — IDs 0x5449 / 0x2260, config 0x4127, shunt 10000 and bus 4000 counts at 0.25 A / 5 V. The same file's negative control proves the check fails against a part that answers only 0x00 or only 0xFF.

## Limitations

- The configuration reset is 0x4127 per the datasheet, not 0xFFFF.
- Power uses |current| (the register is unsigned).

See the YAML header for the full datasheet trace and every named approximation.
