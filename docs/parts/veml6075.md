## Stimulus

Host inputs: `uva`, `uvb` (µW/cm²), `uv_comp1`, `uv_comp2` (counts).

## How to run

1. Place the part and an MCU in Playground, or add it to a system YAML:
   ```yaml
   external_devices:
     - id: "veml6075"
       type: "veml6075"
       connection: "i2c1"
   ```
2. Agent: `labwired_list` → `labwired_describe id=veml6075` → wire → `labwired_validate` → `labwired_run` / `labwired_verify`.
3. Register-level smoke: `cargo test -p labwired-core --test parts_batch5` — ID, UV_CONF and the four channels at default stimulus; `veml6075_counts_follow_integration_time_and_stimulus` covers the integration time, write mask and read-only ID. The same file's negative control proves the check fails against a stand-in that answers only 0x00 or only 0xFF.

## Limitations

- SD does not freeze the outputs; HD is stored only.

See the YAML header for the full datasheet trace and every named approximation.
