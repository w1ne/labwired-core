mode-8 image with 49 selected inputs and passed all four enabled source checks.
Its hosted state controls passed one positive and five assertion-refusal

the unchanged eight service/clock/heap images. A named PyBadge DMA descriptor

poisoned BSS/data startup and image/map/source provenance. It records actual

worker exercises blocking transfer and result consumption. Reentry must refuse
